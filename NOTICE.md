Код проекта распространяется по [LICENSE](LICENSE) (все права защищены). Перечисленное ниже принадлежит третьим лицам и
живёт здесь на своих условиях. Ни один из этих файлов не редактируется: новая версия — новый каталог с датой и
контрольными суммами (`SHA256SUMS`).

## Amazon Selling Partner API — модели (`vendor/amazon/`)

Источник: <https://github.com/amzn/selling-partner-api-models>, коммит `3659f96867bfc669aca7a524c2f95744ff0e4478`.

Лицензия: **Apache License 2.0** — объявлена самими файлами (`info.license` в каждой модели), текст лицензии:
<http://www.apache.org/licenses/LICENSE-2.0>. Файлы распространяются без изменений; провенанс — в
`vendor/amazon/sp-api-models/2026-09-16/SOURCE.md`.

Прочитанное через SP-API в работе системы — «Amazon Information» с собственными условиями хранения (не более 18 месяцев,
без PII); в репозитории таких данных нет, фикстуры синтетические.

## Kaufland Marketplace Seller API — спецификация (`vendor/kaufland/`)

Источник: <https://sellerapi.kaufland.com/swagger.json> (страница: <https://sellerapi.kaufland.com/?page=endpoints>),
снято 2026-09-14, версия 2.44.0. Провенанс и контрольная сумма — в
`vendor/kaufland/seller-api-v2/2026-09-14/SOURCE.md`.

Спецификация **отдаётся публично и без авторизации**, но собственной лицензии не несёт. Копия хранится здесь
неизменённой и только затем, чтобы зафиксировать, ПО КАКОЙ ИМЕННО версии спецификации сгенерирован клиент и написаны
консервативные правила адаптера: без этого утверждения о поведении канала нечем подтвердить.

Права на спецификацию принадлежат Kaufland. Если правообладатель возражает против хранения копии — она будет удалена по
запросу, а провенанс сохранён ссылкой и контрольной суммой.
