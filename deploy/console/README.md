# Развёртывание консоли продавца [Р-159, OQ-221]

До шага 37 консоли как процесса не было: в репозитории жил сервер стенда, который запускают руками, а промышленный
профиль честно отвечал `503` вместо консоли. Теперь консоль — такой же процесс, как планировщик, диспетчер и приёмник:
конфигурация значениями и секретами из файлов, `/healthz` и метрики на отдельном порту, образ с закреплённой версией.

## Что делает процесс

| Что | Как |
|---|---|
| Отдаёт интерфейс | файлами из `apps/console/dist` (сборка `npm run build -w apps/console` — ДО подъёма контейнера: репозиторий примонтирован только на чтение) |
| Отдаёт API | тот же обработчик, что у стенда: адреса `/api/**` и `/inbound/**` |
| Пускает гостя | `POST /api/demo/guest` — наблюдатель демо-тенанта без регистрации [Р-160] |
| Пускает продавца | токеном поставщика identity [Р-78], если задан `REPRACER_CONSOLE_OIDC_*` |
| Сообщает о себе | `/healthz` и `/metrics` на `REPRACER_CONSOLE_METRICS_PORT` |

## Чего он НЕ делает — названо прямо

- **Тенанта продавца в нём завести нельзя**: регистрации и подключения канала из консоли ещё нет (OQ-213). Продавец
  входит туда, где у него уже есть членство; гость — в демо.
- **TLS он не терминирует**: сертификат и домен — забота обратного прокси промышленного профиля
  ([deploy/production](../production/)) [Р-158].
- **Без единого пути входа процесс не стартует**: либо публичное демо, либо поставщик identity, либо оба. Консоль,
  отвечающая `401` на всё, выглядит работающей — и это хуже, чем отказ при старте.

## Секреты

По файлу на роль подключения — их список закрыт в `apps/console/server/config.ts` (`CONSOLE_ROLES`). Роли разные не
для красоты [Р-90]: экраны читают путь решения (`svc_app`), остановки и границы пишет административная роль
(`svc_admin`), вход спрашивает свою (`svc_authenticator`), остатки — свою (`svc_stock`). Выводить их подстановкой из
одной строки, как делает стенд разработчика, в работе нельзя: у ролей разные пароли.

## Демо пересеивается

Публичное демо живёт на симуляторе [Р-151], и гость в нём — наблюдатель: менять он не может ничего, и держит это база
(0124), а не интерфейс. Раз в `REPRACER_CONSOLE_DEMO_RESEED_HOURS` часов мир заводится заново: новый тенант встаёт
рядом, старый останавливается после этого — гость не видит пустого списка миров в момент пересева.
