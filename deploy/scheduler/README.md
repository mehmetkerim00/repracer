# Развёртывание планировщика [Р-129]

Процесс-планировщик [Р-126] запускает периодические работы: ярусный опрос, сверку уведомлений, сверку Amazon по кругу, выгрузку суток в
ClickHouse, закрытие суток цен, обход офферов, секции и удаление по сроку. Состав работ и последствия пропуска —
[docs/evidence/step25-scheduler.md](../../docs/evidence/step25-scheduler.md).

## Запуск

```
cp deploy/scheduler/scheduler.env.example deploy/scheduler/scheduler.env   # заполнить
docker compose -f deploy/scheduler/compose.yaml --env-file deploy/scheduler/scheduler.env up -d
```

## Что даёт развёртывание

| Требование | Как |
|---|---|
| Один экземпляр | `replicas: 1`. Даже при нескольких процессах работу выполняет один — аренда в базе [Р-126]; лишний процесс тратит вызовы каналов |
| Перезапуск при падении | `restart: unless-stopped` и проверка работоспособности: `/healthz` отвечает 503, если последний успешный такт старше пяти тактов (не меньше 5 минут) |
| Конфигурация | переменные окружения (`scheduler.env`), секреты — файлами из `REPRACER_SECRETS_DIR`: в переменных окружения их видно в `docker inspect` |
| Метрики | `http://127.0.0.1:9464/metrics` в формате Prometheus: такты, запуски и объекты по работам, отставание последнего запуска, отстающие работы, сбои отметки. Идентификаторов тенантов и аккаунтов в метриках нет |
| Внешний контроль | отметка во внешнем сервисе каждый такт [Р-127] — [docs/evidence/step26-external-control.md](../../docs/evidence/step26-external-control.md) |

## Секреты

Каталог `REPRACER_SECRETS_DIR` монтируется только на чтение:

| Файл | Что |
|---|---|
| `scheduler_pg_url` | адрес базы для роли `svc_scheduler` (состояние работ, обслуживание) |
| `app_pg_url` | адрес базы для роли `svc_app` (путь решения: опрос, сверка, обход офферов) |
| `exporter_pg_url` | адрес базы для роли `svc_exporter` (выгрузка суток) |
| `ch_ingest_password`, `ch_verifier_password` | пароли ClickHouse |
| `heartbeat_url` | адрес отметки во внешнем сервисе (содержит идентификатор проверки) |
| `channels/<credentials_ref>` | учётные данные аккаунта канала: файл с JSON-объектом строк; имя файла — `credentials_ref` аккаунта с `:` вместо `_` |

Секреты не попадают ни в журнал, ни в сообщения об ошибках: в ошибке конфигурации называется только имя переменной.

## Чего здесь нет

- **Образ не собирается**: контейнер запускает исходники репозитория (`node --experimental-strip-types`). Сборка образа и закрепление по
  digest — при первом развёртывании в среде с доступом к реестру (проверить).
- **Диспетчер записей и приёмник уведомлений** — другие процессы (`services/pricing-worker`, `packages/amazon-notifications`): их
  развёртывания в репозитории пока нет (OQ-190).
- **Сбор журналов и метрик** (куда идут строки JSON и кто читает `/metrics`) — задача среды развёртывания.
