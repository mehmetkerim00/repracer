# ADR-0041: мир тенанта в работе, путь пилота без склеек, настоящий вход обязателен

Статус: принято (шаг 44). Решения: [Р-178…Р-180](../decisions.md).

## Контекст

К шагу 44 каждый кусок пути продавца был проверен живым прогоном — но по отдельности, и между кусками стояли склейки:
прогон панели принимал приглашение вызовом функции базы, прогоны консоли входили имитатором стенда, прогон подключения
канала начинался с посеянного тенанта. Разворачиваемая консоль обслуживала только демо (OQ-234). Собрать путь целиком
значило проверить, существуют ли стыки на самом деле. Трёх стыков не существовало.

## Решение

1. **Мир тенанта — из членства** [Р-178]. Список тенантов пользователя строит функция базы
   `security.console_tenant_worlds` (только роль входа, только не-демо, только действующие членства). Мир собирается
   на запрос поверх тех же хранилищ, что у мира стенда; адаптера канала в нём нет. Демо — отдельный гостевой путь.
2. **Вход на странице** — код авторизации с PKCE у поставщика identity; тот же модуль у страницы и у живого прогона.
   Ссылка приглашения `/invite#токен` запоминается до входа и принимается сразу после; гостевой токен её не примет.
3. **Каталог из обнаружения** [Р-179]. Обнаружение офферов записывает товар, предложение и единицу записи цены (режим
   OFF) функцией узкой роли `repracer_catalog`; витрины — только аккаунта и справочника; идемпотентно. Отложенные
   стражи вставки срабатывают внутри функции её правами.
4. **Исполнитель заданий «все тенанты»**: тенантов с ждущим заданием называет база; хранилище и пулы — одни на процесс.
5. **Промышленный профиль только с настоящим OIDC** [Р-180]: `REPRACER_PROFILE=production`, отказ compose без значений
   и отказ процесса при старте; имитатор стенда и локальные издатели отклоняются. ZITADEL подключается значениями
   (`production.env.example`), не кодом.

## Последствия

- Путь пилота — один прогон `pilot-live.pg.test.ts`, 5 с настоящего времени; модель поставщика identity представляется
  https-именем (база принимает только https-издателей) и слушает на петле — http на петле разрешён только режиму стенда.
- Страница панели оператора пока не входит у поставщика сама (OQ-236).
- У исполнителя «все тенанты» — цикл опроса на каждого тенанта, у которого было задание (OQ-237).
