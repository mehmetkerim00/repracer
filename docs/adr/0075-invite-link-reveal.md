# ADR-0075: ссылка приглашения — оператору один раз, за флагом

**Статус:** принято, шаг 123 ([Р-245]). Решение владельца по аудиту авторизации Amazon 2026-11-14 (Б3).

## Контекст

Пилота заводит оператор: тенант и приглашение владельца [Р-167]. Приглашение уходит письмом. Токен рождается в панели, база хранит только его
отпечаток (0053), а ответ панели называет приглашение идентификатором. Свойство «токен приглашения не попадает в ответ» держалось с шага 40.

Почтового провайдера у проекта нет (OQ-224). В сухом режиме письмо собирается и никуда не уходит, а журнал называет только длины. Ссылка терялась,
и владелец пилота не мог войти. Подключать провайдера сейчас владелец не стал.

## Решение

1. **Флаг развёртывания `REPRACER_INVITE_LINK_REVEAL`**, умолчание `off`. Принимаются только `on` и `off`, иное — отказ при старте. Без флага
   ответ прежний: ссылки нет, токен не покидает панель.
2. **Под флагом ссылка — в ответе действия «пригласить владельца», один раз.** Токен не хранится нигде, кроме отпечатка, поэтому второго показа
   быть не может по построению. Страница панели держит ссылку, пока её не перезагрузили. Ответ — `cache-control: no-store`. В журнал процесса
   ссылка не идёт, письмо по-прежнему собирается (с провайдером оно уйдёт как раньше).
3. **Показ — событие аудита `operator.invitation_link_revealed`, его записывает база той же транзакцией, что выдачу**
   (`security.operator_reveal_invitation_link`, 0229). База пускает показ:
   - только действующему оператору со вторым фактором (`security.operator_acting`, как каждое действие панели [Р-165]);
   - только для приглашения, выданного ЭТОЙ транзакцией этим оператором этому тенанту: событие выдачи с тем же временем транзакции;
   - только один раз на приглашение.
4. **Ослабление — осознанное и только под флагом.** С флагом ссылку видит оператор, а значит, её видит и его браузер. Это вход владельца
   пилота до его первого входа: приглашение одноразовое, живёт не дольше своего срока (по умолчанию 168 ч) и действует только для первого входа
   владельца (0126). Передавать ссылку — только владельцу и не открытым каналом.

## Последствия

- Пилот можно завести без провайдера почты. Когда провайдер появится, флаг выключается одной переменной, и свойство шага 40 возвращается.
- Каждый показ виден в журнале действий операторов (экран «operator actions»).
- Проверки: конфигурация (`apps/operator/test/operator-config.test.ts`), живой прогон двух панелей на одной базе через HTTP и отказы базы
  (`apps/operator/test/invite-reveal.pg.test.ts`), мутации обеих веток стража — строка каталога «шаг 123».
