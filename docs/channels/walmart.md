# Walmart Marketplace — основа будущего адаптера

Шаг 89. Канал работает на симуляторе по правилам настоящего Walmart; живой адаптер против настоящего API — отдельным шагом после
получения ключей. Снимка спецификации в `vendor/` нет: всё ниже — со слов владельца продукта, а всё, что сверх этого, — решение
проекта или вопрос W-nn. Правило репозитория остаётся в силе: факты об API канала — только из снимка; до снимка они не факты, а
исходные данные для проверки.

## Факты владельца (на них равняется симулятор)

| Факт | Где в коде | Проверить живьём |
|---|---|---|
| OAuth 2.0, Token API | `packages/walmart-adapter/src/client.ts` — ключ и секрет клиента → токен доступа | форма запроса токена и срок жизни (W-01) |
| Песочница `sandbox.walmartapis.com`, бой `marketplace.walmartapis.com` | `WALMART_HOSTS` (`descriptor.ts`) | — |
| Лимиты — корзина токенов: каждый запрос тратит токен, пополнение с фиксированной скоростью; превышение — 429 | `pacer.ts`, модель `tests/contract/src/simulator/walmart-channel.ts` | размеры корзин по операциям (W-07) |
| В ответах заголовки `x-current-token-count` и `x-next-replenishment-time` | писатель читает их и ждёт пополнения; модель ставит их на каждый ответ | формат времени пополнения: мс эпохи, секунды или ISO (W-07) |
| Слишком большой фид — 413 | клиент не отправляет фид больше предела; модель отвечает 413 | предел тела фида (W-08) |
| Инвентарь — порядка 200 запросов в минуту (US) | корзина инвентаря модели — 200/мин; описание канала — правило лимита «из заголовков» | точное число и окно (W-07) |
| Цены: одиночное обновление и массовый фид | одиночное `PUT /v3/price`; фид — `submitPriceFeed` с пределом | адреса и формы тел (W-01) |
| Инвентарь: одиночно, массово и по складам (ship nodes) | одиночное `GET/PUT /v3/inventory?sku=` — склад по умолчанию | склады с отдельным количеством (W-04) |
| Правило неконкурентной цены: тот же товар заметно дешевле на другой площадке или у Walmart 1P — листинг снимается с публикации (unpublish) | модель: порог 10 % (параметр), причина и цена «в другом месте» в ответе о товаре; адаптер: `listingStatuses`, наблюдение `liveness` | порог, называет ли Walmart причину и цену, публикует ли обратно сам (W-10, W-11) |

## Что сделано на симуляторе

- **Канал WALMART** в базе (0186): витрина `WALMART_US` — на экранах walmart.com, USD, нетто, sales tax при покупке [Р-58]; возможности
  по полям (цена и количество — аккаунт + витрина + SKU), источник конкурентов `WALMART_BUY_BOX`, снятие системной остановки — только
  человеком. Профиль рынка `us` (и `global`) предлагает Walmart; в `eu` его нет.
- **Подключение** — в списке каналов, но «ждёт платформу»: пока нет наших ключей Walmart, подключить нельзя, и экран говорит это словами.
  Тень и бой — свойства аккаунта, как у всех каналов [Р-169, Р-170]; бой на walmart.com закрыт, пока граница суток не подтверждена
  [Р-172, W-02]. Запись количества по Р-202 — выключена до подтверждения владельца.
- **Писатель и корзина токенов**: каждый запрос проходит корзину своего семейства (цена, инвентарь, товары, Buy Box, фиды, токен);
  пустая корзина — ждём названного пополнения; 429 всё же пришёл — ждём и повторяем один раз. Проверено: 40 записей цены через корзину
  на 5 токенов — ни одного 429 у канала; клиент, не читающий заголовки, на той же корзине получает 429 (`walmart.simulator.test.ts`).
- **Правило неконкурентной цены**: в демо у двух товаров цена на walmart.com $24.99, а тот же товар в другом месте — $19.99; Walmart
  снимает их с публикации. Консоль показывает состояние «Unpublished (uncompetitive price)» у предложения и событие в журнале экрана
  «Stop pricing» с объяснением. **Движок это не чинит** — автоматический ответ на снятие с публикации — отдельное решение владельца.
- **Демо США** — walmart.com рядом с amazon.com и ebay.com: 12 предложений, склад «Warehouse Newark, DE», конкуренты Buy Box — три
  поведения (дрейф, подрезчик, волна), неделя тени прожата вместе с остальными витринами.

- **Шаг 97 [Р-219…Р-221]: именованный рынок Buy Box** — режим модели `NAMED_WAVES`: у товара три вымышленных продавца пула
  (`tests/contract/src/simulator/buybox-rule.ts`) с волнами своей фазы и размаха и доставкой; победитель — документированная формула модели
  (минимальная цена с доставкой; бонус за исполнение каналом у Walmart не действует — исполнения модель не называет, W-05), при равенстве —
  прежний держатель; продавец Buy Box назван в ответе. Прежний режим (три безымянных конкурента шага 89) — по умолчанию. Демо США — на новом
  режиме, стратегия walmart.com — «Win the Buy Box» с подъёмом при удержании.

## Открытые вопросы W-nn

| Код | Вопрос | Как закрыть |
|---|---|---|
| W-01 | Адреса операций, формы тел и заголовков (`WM_SEC.ACCESS_TOKEN`, `WM_QOS.CORRELATION_ID`, `WM_SVC.NAME`), форма запроса токена | снимок спецификации в `vendor/walmart/` до живого адаптера |
| W-02 | Граница суток витрины walmart.com (для суточной свёртки и бюджетов) | поддержка Walmart или неделя тени [Р-204] |
| W-03 | Цена: применяется сразу или асинхронно; как подтверждается | первая боевая запись |
| W-04 | Склады (ship nodes): есть ли у продавца склады с отдельным количеством, какой склад по умолчанию | первая боевая запись количества |
| W-05 | Какой API и с какой частотой отдаёт цены конкурентов (Buy Box) | снимок и песочница |
| W-06 | Налоговая база цены walmart.com в API | поддержка Walmart |
| W-07 | Размеры корзин по операциям; формат `x-next-replenishment-time` | заголовки первых ответов песочницы |
| W-08 | Предел тела фида, после которого 413 | документация или песочница |
| W-09 | Заказы и уведомления: чтение строк заказов, подписки — в этом шаге «не поддерживается» | живой адаптер |
| W-10 | Порог правила неконкурентной цены; называет ли Walmart причину снятия и цену «в другом месте» | документация и первый случай на бою |
| W-11 | Публикует ли Walmart листинг обратно сам, когда цена снова конкурентна | первый случай на бою |

## Чего нет в этом шаге (и когда вернуться)

- Живой адаптер против песочницы и боя — после ключей Walmart: снимок спецификации, сверка W-01…W-11, подключение продавцом по OAuth.
- Автоматический ответ движка на снятие с публикации — решение владельца (отложено с этим событием возврата).
- Чтение заказов Walmart и резервации по ним — с живым адаптером (W-09).
