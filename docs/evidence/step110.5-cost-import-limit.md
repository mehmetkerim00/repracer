[отложенного](../deferred.md)); у медленной группы до прежнего предела оставалось 7–18 с.

## Решение

| Что | Как |
|---|---|
| Предел | временно 90 с — `COST_IMPORT_SECONDS`, цель `COST_IMPORT_TARGET_SECONDS` = 60 с (`tests/contract/src/cost-import-limit.ts`); запас — полтора выброса |
| Обратный билет | строка «99 (импорты), 110.5» [отложенного](../deferred.md): «после ускорения триггеров cost_profile ВЕРНУТЬ предел к 60 с»; держит `tests/contract/src/cost-import-limit.test.ts`, помощник `tests/contract/src/return-ticket.ts` общий с билетом 110.3 |
| Пакетное применение | ближайший продуктовый шаг после уже выданных заданий: 10 000 строк — заметно ниже 25 с на быстром раннере, ниже 60 с на медленном; затем предел возвращается по билету |
| Правило работы | пределы времени — от медленной группы раннеров с запасом; сработал без регрессии кода — времянка с билетом без решения владельца (CLAUDE.md, «Правила работы в репозитории») |

## Красное сначала

| Что | Как показано |
|---|---|
| Обратный билет | до строки в отложенном тест красный: «предел 90 с выше цели 60 с, а в docs/deferred.md нет строки «cost_profile … ВЕРНУТЬ предел к 60 с»»; зубы — строка без «ВЕРНУТЬ предел к 60 с» краснит, предел, равный цели, билета не требует |
| Предел 90 с | решение владельца, не исправление дефекта — исключение, названное явно |
