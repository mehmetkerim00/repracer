# Шаг 123: ссылка приглашения — оператору один раз, за флагом [Р-245]

Решение владельца по аудиту авторизации Amazon 2026-11-14 (Б3): почтового провайдера сейчас нет, малая правка — показ ссылки приглашения оператору один
раз, только в панели, только со вторым фактором, с записью в аудит, за флагом `REPRACER_INVITE_LINK_REVEAL` с умолчанием off; ослабление — в ADR
([ADR-0075](../adr/0075-invite-link-reveal.md)).

## Что сделано

- Конфигурация панели: `REPRACER_INVITE_LINK_REVEAL` — `on` или `off` (умолчание), иное — отказ при старте; строка старта панели называет флаг.
- Действие «пригласить владельца»: под флагом в ответе — `invitationUrl` (адрес приёма приглашения с токеном во фрагменте), ответ `no-store`; страница
  панели печатает её с пометкой «shown ONCE, not stored anywhere». Без флага ответ прежний.
- База (0229): `security.operator_reveal_invitation_link` — событие аудита `operator.invitation_link_revealed` той же транзакцией, что выдача; только
  действующий оператор со вторым фактором, только приглашение этой транзакции этого оператора этого тенанта, только один раз. Функция выдачи не менялась.
- Развёртывание панели: флаг в `deploy/operator/compose.yaml` (умолчание off), пример — в `operator.env.example`, README — абзац о флаге.

## Красное сначала

| Тест | На старом коде |
|---|---|
| `apps/operator/test/operator-config.test.ts`, «step 123 [Р-245] …» | Красный: флага нет |
| `apps/operator/test/invite-reveal.pg.test.ts`, «with the flag on, the operator gets the invitation link once …» | Красный: ссылки в ответе нет |
| там же, «the database keeps the reveal honest …» | Красный: функции показа нет |
| там же, «without the flag the answer is as before …» и «without a second factor nothing is issued …» | Зелёные и на старом коде — контроли прежнего свойства; зубы стража — мутациями |

Живой прогон — настоящий процесс панели (`startOperatorPanel`) по HTTP, две панели на одной базе: с флагом и без. Токен ссылки проверяется по отпечатку
в базе — владелец сможет принять именно это приглашение.

Мутаций строки шага — 2 из 2 пойманы своей проверкой (обе ветки стража показа). Миграция 0229.
