# Шаг 128: рамки Amazon без прочитанных значений — в бою прежний отказ включения; копии пилота — `pull` [Р-250, Р-249]

Решения владельца по докладу шага 127 (2026-11-14):

1. «Копии базы пилота — вариант pull: машина оператора забирает копии раз в сутки по SSH. R2 не включаем: там может всплыть запрос способа
   оплаты, а любые возможные списания — только с одобрения Мердана; пересмотрим при go-live. В README пилота допиши прямо: смоук покраснеет,
   если свежей вынесенной копии нет… — в том числе если машина оператора долго выключена».
2. «П1 в бою — правило отключить: в бою включение автоцены у SKU с заранее известными рамками Amazon отказывает с честной причиной, как раньше.
   В тени — как сделано в шаге 127, с пометкой «Price held: Amazon bounds». Стоп записи и алерт для рамок, появившихся ПОСЛЕ включения,
   остаются… CRITICAL должен означать неожиданное; предсказуемый стоп по известному заранее состоянию — шум».

## Что сделано

- **0231** — `channel_data.offer_channel_pricing_active` называет рамки без значений в валюте предложения `CHANNEL_BOUNDS_PRESENT` у аккаунта с
  `write_mode = 'LIVE'`; страж привязки — тем же условием. Отсюда, как до шага 127, в бою: назначение стратегии и включение движка (0085),
  стратегия по умолчанию (0199, «not assigned», причина `CHANNEL_PRICING`) и привязка (0205) — отказ своей причиной. Ролям стратегии по
  умолчанию и каталога — чтение одного столбца `channel_account.write_mode` (правило зовётся в их транзакциях).
- **Двойник в памяти** — то же правило (`channelPricingBlock`, режим аккаунта посева).
- **Консоль** — строка наблюдения ценообразования канала несёт режим аккаунта (`accountLive`, PostgreSQL — тем же чтением). В бою —
  пометка «Blocked: Amazon bounds» (`CHANNEL_BOUNDS_LIVE`, тон остановки, включение недоступно, причина и что сделать в Seller Central),
  страница пола — «в бою автоцену не включить, пока рамки не убраны»; импорт стратегий — `CHANNEL_PRICING`. В тени — пометка шага 127 без
  изменений. EN/DE/ES/FR по глоссарию (repricing · precios automáticos · tarification automatique; live · en vivo · mode réel).
- **Рамки после включения** — не трогались: включённое предложение не выключается задним числом, первая запись — адаптер, BLOCKED и CRITICAL.
- **Копии пилота** — `pilot.env.example`: `REPRACER_BACKUP_OFFSITE=pull`; README `deploy/pilot` §8 — выбор пилота и почему не R2, когда
  смоук краснеет из-за выноса (отметка `OFFSITE_PULLED` старше 26 ч: машина оператора выключена, спит, без сети дольше суток; дольше 7 суток —
  копии удаляются на сервере раньше, чем их заберут) и что смоук идёт только при выкладке и вручную. Р-249 уточнено в decisions.md.
