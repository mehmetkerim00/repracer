## Спецификация

### Столбцы по умолчанию (подход тикета)

**Было:** Offer · Status · Current price · Effective floor · Maximum price · Strategy · (Channel says, если есть) · действия.

**Стало:** Offer · Status · Current price · **Buy Box holder** · Effective floor · Strategy · (Channel says) · действия.

- Один сигнал конкуренции — держатель Buy Box — включён по умолчанию; остальные колонки Buy Box — за «Columns», как были.
- Maximum price уходит за «Columns»: без него включение отказывает, и окно включения называет его в списке недостающего (ниже).
- Выбор колонок зрителя, сохранённый в браузере, остаётся его выбором; новые умолчания — у тех, кто ещё не выбирал.

### Статус (UX-03)

| Состояние | Было | Стало |
|---|---|---|
| Движок включён, аккаунт в бою | «On» · «The price is calculated automatically» | без изменений |
| Движок включён, аккаунт в тени | «On» · то же | **«On · shadow mode»** (тон внимания) · «Calculated, not sent to your store» |
| Остановлено человеком | «Stopped» · «A person stopped all price changes for … since …» | «Stopped» · **«by <кто>, <когда>»** (полная фраза — подсказкой) |

- Режим аккаунта — из строки аккаунта хранилища (шаг 146: `channelAccounts().writeMode`).
- Итоги таблицы («on N») не меняются: включённое в тени — включено.

### Пустые значения — словами, не моноширинно (UX-04, скрин владельца)

| Ячейка | Было | Стало |
|---|---|---|
| Текущая цена без цены | `no value` моноширинно | «No price yet» — обычным шрифтом, приглушённо |
| Пол без пола | `no value` + «Minimum price is not set» | «Not set» — обычным шрифтом; подпись прежняя — «Minimum price is not set» (уточнено при правке: она уже говорит, что сделать) |
| Максимальная цена без значения | `not set: not set` | «Not set» — обычным шрифтом |

- Моноширинный шрифт (`cur`) — только у сумм. Модель строки говорит, сумма ли это (`currentPriceMissing`, `floor.missing`, `maxPriceMissing`), и экран не ставит `cur` пустому значению.
- Без пустых дыр: прочерк и пропуск — короткой приглушённой строкой, ширина колонки — по содержимому, как у сумм.

### Окно включения перечисляет всё недостающее (UX-05)

- Строка Offers несёт список недостающего для включения: себестоимость с комиссией (`cost`), минимальная цена, максимальная цена.
- Окно отказа включения ниже причин сервера показывает «To switch it on, add:» и по пункту на каждое недостающее со ссылкой:
  - себестоимость — Costs & floors → Import;
  - минимальная и максимальная цена — правка границ с выбранным предложением.
- Сам отказ (причины сервера и базы) не меняется.
