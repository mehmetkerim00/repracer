# Шаг 157: Stop pricing — сначала состояние, затем действия — #28 [Р-254]

Подход тикета #28:
1. одна строка состояния («Pricing is running» / «Stopped by …, когда, note …»);
2. кнопки остановки и возобновления по областям;
3. список активных остановок.

Дальше:
- системные остановки и недоверие каналу — только когда они есть, иначе одной строкой «нет» с подробностями по запросу;
- журнал аудита — раскрываемым разделом, фильтры и выгрузка прежние;
- семантика остановок не меняется: возобновление всего пространства — со вторым фактором и запиской.

Спецификация записана ДО правки.

## Спецификация

### Сверху вниз

1. Заголовок, подзаголовок, «Pause is safe…» — без изменений.
2. **Строка состояния** (новое, `p.stop-headline` с пилюлей тона):
   - **ничего не остановлено** — «Pricing is running» (ok);
   - **есть остановка человеком** — «Stopped: <область> — by <кто>, <когда>. Note: <записка>» (stop). Вся область пространства — первой; ещё остановки — «· N more»;
   - **есть системные остановки или недоверие** — следом через «·»: «N storefront halts by the system», «N channels distrusted by the system».
3. **«Stop by a person»** — без изменений: области (пространство, аккаунты, витрины), «что остановка не останавливает», активные остановки, история.
4. **Системные остановки и недоверие:**
   - есть активные или были — прежние разделы;
   - нет ни тех, ни других — одна строка «No storefront halts and no distrusted channels.» и раскрытие «How the system stops prices» с прежними двумя пояснениями (`humanIntro` не трогается).
5. **«Three kinds of stop»** — таблица прежняя, раскрываемой панелью (`details.card.more-block`). Свёрнута; число активных — в строке состояния.
6. **Журнал аудита** — раскрываемой панелью; период, выгрузка и страницы внутри — прежние. Свёрнут, раскрытие помнит браузер (`useOpenBlocks`).

### Токены

Только существующие — `Badge`, `notice`, `card`, `more-block`. Новых цветов, шрифтов и теней нет.
