## Спецификация

### Margin

- Маржа при текущей цене — той же функцией, что у Gate и разбивки пола (`marginBpAtPrice`), себестоимость в валюте предложения курсом ЕЦБ, как хранилище (`costInScopeCurrency`).
- Текст — процентом («23.40%», минус у отрицательной).
- Цены нет — прочерк, себестоимости нет — «No unit cost»; обычным шрифтом, приглушённо (шаг 148).
- Колонка видна по умолчанию, за «Columns» её можно скрыть.

### Health

- Пилюли, которые стояли в ячейке предложения, — одной колонкой «Health»:
  - «Floor above ceiling» (stop);
  - конфликт с рамками цены канала;
  - «Fee estimate expired …»;
  - «Clearance».
- **Первой — важнейшая** (stop раньше внимания, затем по этому порядку); остальные — «+N», полный список — подсказкой.
- **Свежесть** данных конкурентов по предложению в строке Offers сейчас нет (есть по аккаунту — строка состояния шага 146). Не выдумываем: в Health не входит, названо в отчёте.
- **«Channel says»** (заметки канала: Automate Pricing, рамки без значений, «не продаётся», Walmart) — своей колонкой, как прежде: у пилюль там «что делать» (шаг 96). *Изменено при правке — см. «Что сделано»: колонка влилась в Health.*
- **Колонка видна по умолчанию, только когда на странице есть что показать** — как «Channel says». Колонка из одних прочерков — находка правила шага 96.2.
