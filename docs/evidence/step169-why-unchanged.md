# Шаг 169: «Why didn't my price change?» — #36 [Р-254]

Решение владельца 2026-11-18: предложения #36, #35 и #34 (ярус 2) строятся сейчас, по порядку. Мердан получает уведомление, вето в тикетах сохраняется.

Для #36:
- только из СОХРАНЁННЫХ причин решений без изменения цены — никакой причинности задним числом;
- причин за период нет — честное «no decision was computed in this period» с объяснением, когда решения появляются;
- вход — с карточки и строки предложения и из пустых выборок журнала цен;
- ответ — как квитанция: одна фраза сути, доказательства по раскрытию.

## Спецификация (до правки)

**Страница** `unchanged/<предложение>` с периодом (24h / 7d / 30d / свой). Окно — не глубже 30 суток: решения живут в базе 30 суток [Р-28].

**Ответ строится только из сохранённого** — из решений этого предложения за период: страница журнала решений, свежие первыми.

| Последнее решение | Строка сути | Фраза |
|---|---|---|
| без изменения цены (`NO_CHANGE`) | «The price stayed as it was» | заголовок квитанции этого решения: сохранённая причина с суммами, теми же словами, что квитанция |
| отказ Price Gate | «The price stayed as it was» | заголовок квитанции: отказ с границей и отклонением |
| одобрено в тени | «The price stayed as it was» | заголовок квитанции: удержано тенью, в магазин не ушло |
| одобрено и отправлено | «The price did change» | заголовок квитанции этого изменения |
| решений нет | «No decision was computed for this offer in this period.» | когда решения появляются |

Рядом с фразой — пилюля статуса квитанции (Rejected / Held in shadow mode / No change / …).

**Факты под фразой** — из тех же строк, ничего не выводится:
- **с какого времени** — непрерывная цепочка последних решений с той же сохранённой причиной: исход и код причины. Дошла до конца выборки, а решений больше — «at least since»;
- **сколько проверок** — счётчик живой строки [Р-241], те же слова, что в журнале («Same state on N more checks, last …»);
- **последнее изменение цены в периоде**, если оно было.

**Когда решений нет** — объяснение, без догадки о причине: решение записывается, когда движок проверяет предложение:
- пришли новые данные конкурентов;
- пересчёт по расписанию, не реже раза в сутки;
- изменились себестоимость, комиссии или границы.

Ничего не записывается, пока автоцена предложения выключена, пока цены остановлены, пока его границы нельзя посчитать.

**Доказательства по раскрытию:**
- квитанция последнего решения целиком (тот же вид, что «Why this price», свёрнута) и ссылка на неё;
- решения предложения за период — строки журнала (время, статус, причина, проверки).

**Входы:**
- **страница предложения** (Bounds and price floor), карточка «At a glance» — ссылка «Why didn't my price change?»;
- **строка Offers** — та же ссылка в колонке действий, рядом с «Bounds» и «Competition →»;
- **Price changes** — пустая выборка журнала записей с выбранным предложением (фильтр Offer) ведёт на ответ этого предложения за тот же период; без выбранного предложения — подсказка выбрать его.

**Тексты** — EN/DE/ES/FR. **Токены** — существующие токены темы (Р-255). Миграций нет.

## Сделано

- **Модель** `unchangedView` ([packages/console-model/src/unchanged.ts](../../packages/console-model/src/unchanged.ts)): строки — страница журнала решений предложения за период (свежие первыми), фраза — заголовок квитанции последнего решения, пилюля — её статус словарём шага 137.
  - «Цена осталась прежней» — последнее решение без изменения, отказ, пауза или одобрено в тени [Р-169]; «задала новую цену» — одобрено в бою, и рядом строка отправки квитанции: дошла ли цена до магазина, говорит квитанция, а не ответ.
  - «С какого времени» — цепочка последних решений с тем же исходом и кодом причины; дошла до конца показанного — «At least since …, no earlier decision is shown here» (старше ничего не угадывается).
  - Проверки после последней строки — словами журнала [Р-241]; последнее изменение цены в периоде — если оно было.
  - Решений нет — «No decision was computed for this offer …» и когда решения появляются; доказательств нет — нечего сворачивать.
- **Маршрут** `GET /api/worlds/<мир>/unchanged/<предложение>?period=…`: окно не глубже 30 суток [Р-28], отрезанное — названо; 50 последних решений и квитанция первого; чужое предложение — 404, неверный период — 400.
- **Экран** `unchanged/<предложение>[/<период>]` — пункт меню Offers; карточка ответа, ниже свёрнутые «Show the receipt of this decision» (квитанция целиком без шапки страницы — `TraceView embedded`) и «Decisions for this offer in this period (N)» (строки журнала решений).
- **Входы:** строка Offers (колонка действий, после «Competition →»), карточка «At a glance» страницы предложения, пустая выборка журнала цен (записи и решения): с выбранным предложением — ссылка на ответ за тот же период, без него — подсказка выбрать предложение.
- **Тексты** EN/DE/ES/FR (`ui.unchanged`, имя страницы для «назад» квитанции — `ui.app.screens.unchanged`). Токены — существующие; миграций нет.
