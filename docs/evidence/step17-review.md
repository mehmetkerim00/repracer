# Ревью шага 17 — итог независимого ревьюера

Ревьюер работал в своих копиях базы из шаблона и ничего не менял в репозитории. Ниже — сводка находок; каждая проверена экспериментом.

| № | Уровень | Находка | Блокирует шаг 18 |
|---|---|---|---|
| 1 | Высокий | Р-97: `security.admin_only_writes()` сравнивает привилегию без столбца. UPDATE `write_scope` (`pricing_mode`, стратегия, статус) выпал из стража и аудита: административный сервис меняет режим без человека и без события. Проверка 0067 опирается на ту же функцию и дыру не видит; комментарий в `store.ts:setPricingMode` неверен | да |
| 2 | Высокий | Р-97, Р-2: страж проверяет только «действующий участник». Оператор без второго фактора записывает согласие на НЕОБРАТИМУЮ миграцию eBay от имени владельца; автором в аудите стоит оператор, а в строке — владелец | да |
| 3 | Средний | Р-98: гонка двух приёмов приглашений даёт две действующие привязки одного поставщика (уникальность заменена триггером без блокировки) | да |
| 4 | Средний | Р-96: права по таблице, а не по столбцам. Путь решения вставляет остановку, «снятую вручную владельцем», закрывает случай ASK_HUMAN от имени владельца, снимает HELD/BLOCKED у единицы записи | да |
| 5 | Средний | Р-97: UPDATE `pricing_halt` (`next_review_at` +10 лет) у административного сервиса — без аудита и без проверки роли | да |
| 6 | Средний | Р-94: 104 вызова `expect_fail` без причины; `smoke_path.sql` ждёт SQLSTATE 42501, который дают и защитные триггеры | да |
| 7 | Средний | Р-95: мутация засчитывается падением ЛЮБОЙ проверки строки; часть защит шага 17 без строки в каталоге (`external_identity_one_active`, фильтр отзыва, аудит перепривязки, `lock_decision_products`, ветки видов значений и др.) | да |
| 8 | Средний | Находка 6 закрыта частично: виды значений проверяются только у `params` причин; поля формата r80.1 (`currentMinor`, `currency`, `gate.fx.*`, `context.*`) принимают произвольный текст; `id`, `ratio`, валюта почти не ограничены | да |
| 9 | Низкий | Р-97: строки платформенного тенанта пишутся административным сервисом с любым (даже несуществующим) пользователем и без аудита | нет |
| 10 | Низкий | Р-98: владелец одного тенанта перепривязывает вход пользователя во все его тенанты; аудит — только в одном | нет |
| 11 | Низкий | Р-96: лишние права (UPDATE всех столбцов `edit_budget`, `write_scope_sync_state`, DELETE `channel_write`); 0067 не проверяет членство `repracer_app` в служебных ролях | нет |
| 12 | Низкий | Автоматическое снятие подделываемо через наблюдения выборки (OQ-143); ADR-0017 утверждал обратное — исправлено | нет |
| 13 | Низкий | Расхождения доказательств: лог тестов был красным (заменён финальным: 237 из 238, падает только тест за брокером); «0 непойманных мутаций» подтверждено полным прогоном с одной непойманной и перепрогоном строки OQ-151 | нет |

Без находок: изоляция тенантов и RLS; секреты и хеши в событиях аудита; код миграции листингов eBay (отсутствует); обход OQ-151 через RETIRED→ACTIVE (невозможен).
