# Шаг 173: чеклист готовности без страницы тени — находка журнала медленных запросов QA-A

После выкладки шага 170 журнал стенда QA-A (шаг 164) записал строку `SLOW_REQUEST`: `GET /api/worlds/demo%2Fus/readiness` — 2240 мс, порог — 2000 мс.

**Причина.** Маршрут чеклиста ради двух полей читал страницу тени целиком: сводку недели, эпизоды пола, график по часам, дайджесты, «потратило бы». Два поля:
- свойства витрин аккаунтов (Р-172);
- признак закрытой для боевых записей базы (шаг 119).

**Правка:**
- `PgShadowStore.readinessInputs(tenant)` — ровно эти два запроса страницы тени; разбор свойства — одна функция `propertyRow` у страницы и у чеклиста;
- порт тени (`ShadowReader`) — необязательный метод; у тени без него маршрут читает страницу тени, как раньше.

## Красное сначала

`packages/pricing-store-pg/test/readiness-inputs-step173.pg.test.ts`:
- мир с аккаунтом amazon.com в тени;
- лёгкое чтение = поля страницы тени (у amazon.com есть свойства витрины).

На коде шага 172 — `shadow.readinessInputs is not a function`, после — 1 из 1. Число на стенде — после выкладки (журнал медленных запросов). Миграций нет.
