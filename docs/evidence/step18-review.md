# Ревью шага 18 — итог независимого ревьюера

Каждая находка проверена экспериментом в собственной копии базы (review18_a…d из шаблона, удалены). Роли кластера не менялись.

| № | Уровень | Находка | Блокирует шаг 19 |
|---|---|---|---|
| 1 | Высокий | Административный сервис меняет `write_scope.status` (ACTIVE→HELD→BLOCKED→ACTIVE) без пользователя сессии и без аудита: `status` — столбец пути решения, поэтому исключён из административных, а страж переходов освобождает любую административную сессию | да |
| 2 | Высокий | Р-101 обходится через `migration_consent_item` (владелец без второго фактора добавляет листинг в выданное согласие; у `listing_migration_check_id` нет FK) и `migration_consent_revocation` (отзыв от имени другого участника) | да |
| 3 | Высокий | Путь решения вставляет intent `MANUAL` с `created_by_membership_id` владельца (INSERT на всю `price_intent`) — «ручная цена» проходит мимо системной остановки (Р-51) | да |
| 4 | Средне-высокий | Административный сервис вставляет `pricing_halt` задним числом (аудит — как SYSTEM) и сразу «снятой вручную владельцем» (страж снятия стоит только на UPDATE) | да |
| 5 | Средне-высокий | OQ-153 обходится: `SET ROLE repracer_retention` даёт прямой DELETE привязок и отзывов у действующего пользователя | да |
| 6 | Средний | Гонка привязок закрыта только в READ COMMITTED; в REPEATABLE READ две привязки фиксируются | да |
| 7 | Средний | Виды полей слепка обходятся скалярами внутри массивов, объявленных как массивы объектов (`strategy.steps: [1799, "undercut 5"]`) — текст и числа попадают в вечное ядро (Р-85) | да |
| 8 | Средний | Р-99 для смоук-проверок не выполнен: исход «EXPECTED FAILURE HAD ANOTHER REASON» засчитывается своей поимкой; мутация «согласие от своего имени» отмечена CAUGHT, хотя отказала проверка роли | да |
| 9 | Средний | Метки смоук-проверок сверяются как подстрока (`append-only channel_data.price_decision` — префикс `…_snapshot_ref`); причина теста совпадает с текстом `expected` в `assert.match` при любом отказе; часть причин общие | да |
| 10 | Средний | Проверка схемы 0071 не сверяет столбцовые права роли остатков и не замечает триггеры с `WHEN (false)` | да |
| 11 | Средний | CI с мутационной проверкой без `--measure` будет красным при 5 непойманных — в документах не сказано | нет |
| 12 | Низкий | Матрица ролей для `write_scope` грубая: всё — ENABLE_REPRICING (оператор меняет валюту, налоговый режим, синхронизацию остатка) | нет |

Не подтвердились утверждения шага 18: удержание и снятие блокировки — только человек; согласие eBay полностью под Р-101; путь решения
не пишет действия человека; гонка привязок закрыта; удаление привязок только у отключённого; виды у каждого скалярного поля;
права роли остатков сверяются в обе стороны; мутация поймана только своей проверкой (для смоук-проверок); OQ-152 закрыт
(у роли остатков нет публикации остатка в каналы); Р-103 проверяет UPDATE, но не DELETE.
