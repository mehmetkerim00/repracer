# Шаг 180: сворачиваемая навигация — #38, часть 1

Решение владельца 2026-11-25: #38 строится без дополнительного одобрения (собственные просьбы Мердана из «QA-A Testing 2.0»), после #39.

## Что стало

На широком экране (от 1012 px, брейкпоинт Primer) у боковины есть кнопка «Collapse the menu»:
- боковина сжимается до иконок пунктов меню;
- имя пространства и заголовки разделов скрыты;
- подпись пункта визуально спрятана, но остаётся доступным именем ссылки; при наведении — подсказка с именем пункта;
- «Expand the menu» возвращает полную боковину.

Выбор — предпочтение зрителя в этом браузере (`localStorage`, ключ `repracer.nav`, как тема):
- все чтения и записи — в try/catch;
- без хранилища боковина развёрнута.

На узком экране сворачивания нет: там прежняя выдвижная панель (шаг 85). Иконки — уже встроенные Octicons `chevron-left` и `chevron-right`, новых путей нет.
