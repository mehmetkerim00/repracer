# Шаг 183.1: смоук шага 107 — гонка смены экрана

Быстрый прогон шага 182 ([45630035953](https://github.com/mehmetkerim00/repracer/actions/runs/45630035953)) был красным одним тестом в `fast (2/2)`. Это смоук шага 107: «evaluate: Uncaught» на вводе суммы распродажи — поля нет. Прогон шага 183 ([45634253004](https://github.com/mehmetkerim00/repracer/actions/runs/45634253004)) — тот же код плюс шаг 183 — зелёный на обоих шардах; локально тест зелёный. Ворота шага 182 слияние остановили (`FAST_RED`), в main шаги 182–183 ушли воротами шага 183 по его зелёному прогону.

## Причина

Помощник `go` теста ставил адрес и сразу звал `settled`. Хеш применяется следующей задачей, и `settled` мог застать прежний экран (Offers) уже без загрузки: тест вводил сумму распродажи на Offers. Между двумя страницами границ подряд та же гонка давала бы проверку «нет предупреждения без конфликта» по прежней странице.

## Что стало

`go(route, ready)` ждёт признак целевого экрана:
- Competition — ссылку продавца;
- Offers — таблицу;
- страница границ — ссылку «Change this floor» именно этого предложения: у двух страниц границ подряд общий раздел рамок канала;
- форма распродажи — её поле суммы.

Красного сначала нет: гонку не воспроизвести детерминированно. Красное — прогон CI выше. Миграций нет.
