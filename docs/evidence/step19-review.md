# Ревью шага 19

Ревьюер — отдельный агент. Предмет — коммит `7a63ace` против `15644f6`. Ограничения ревьюера:

- рабочие базы не трогать;
- `prepare.sh` и мутационную проверку не запускать;
- роли не менять;
- файлы и git не менять.

Эксперименты ревьюер вёл в собственной копии `review19_a` из шаблона и после работы её удалил. Одна оговорка. Чтобы построить смоук-мир в копии, ревьюер прогнал `tests/db/smoke_*.sql`, а в `smoke_setup.sql` есть `CREATE ROLE svc_* … IF NOT EXISTS`. Роли уже существовали, поэтому команда ничего не создала. Роли — общие для кластера, и такой прогон ограничениями не разрешался.

## Не подтвердились утверждения шага 19 (по ревью)

- «Причина теста сверяется с фактическим результатом» — до исправления находки 1 это было неверно.
- «Метки сверяются целиком» было верно только для смоук-проверок.
- «В административной сессии любое изменение — от человека с ролью и в аудите» — неверно (находки 3 и 7).
- «`svc_stock` без цен» — неверно: бюджет цен eBay меняется через обход `only_from_trigger` (находка 2). Вытеснение записей было сломано (находка 6).
- Р-107 как закрытие находки 3 ревью шага 18: метка MANUAL закрыта, обход остановки через `rule_code` остался (находка 4).
- «Элемент согласия — по существующей предполётной проверке» формально верно, по сути нет (находка 5).

## Подтвердилось

- Смоук-часть раннера: исход «HAD ANOTHER REASON» не засчитывается, метка сверяется целиком. Итоги 146/0 и 124/22 совпадают с логами.
- Удалённую проверку участника держит `audit_event_check1`, в том числе для платформенного тенанта и отозванных участников. Таблицы OWN_GUARD `price_stop`, `pricing_halt_review` и `membership` защищены своими стражами.
- Статус единицы записи в административной сессии требует человека с ENABLE_REPRICING и пишется в аудит.
- Элемент согласия: владелец, давший согласие, второй фактор, та же транзакция. Отзыв: от своего имени, второй фактор, роль проверяет общий страж.
- `price_intent_manual_guard` с SECURITY DEFINER:
  - `search_path` зафиксирован;
  - PUBLIC отозван;
  - EXECUTE у `repracer_owner` ничего не открывает.
- Роль остатков видит и меняет только единицы QUANTITY. Цена в запись и в историю отклоняется.
- 0072 восстановил SECURITY DEFINER у `external_identity_one_active`, правило 14f это ловит. Привязка создаётся только в READ COMMITTED.
- Скаляры в массивах слепка отклоняются рекурсией.

Итог после исправлений: 148 мутаций, не поймано своей проверкой — 0, контроль — 176 проверок ([step19-mutation-final.md](step19-mutation-final.md)); сразу после исправления раннера — 2 из 148 ([step19-mutation-runner-fixed.md](step19-mutation-runner-fixed.md)).
