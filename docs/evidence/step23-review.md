## Подтвердилось

- **Снятие недоверия отказывает** (опыты):
  - оператор со вторым фактором — роль;
  - владелец без второго фактора — второй фактор;
  - от чужого членства — пользователь сессии;
  - путь решения — права;
  - административный сервис без пользователя — нет человека;
  - смена витрины или причины — права по столбцам.
- **Недоверие держит порог цены канала.**
- **Маршрут продавца** — только функцией, у пути решения нет EXECUTE, отключённый аккаунт не маршрутизируется.
- **Р-119:** на Amazon проверка выборкой отвечает `MANUAL_ONLY`; `strategy_unmet` совпадает с кодом.
- **SigV4** совпала с независимым вычислением. В алертах приёмника нет SellerId, текста ошибки AWS и ключей.
- **Остановок `CHANNEL_PRICE_BASIS_MISMATCH` в `pricing_halt` больше нет.**
