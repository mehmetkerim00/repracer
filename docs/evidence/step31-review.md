## Что ревьюер проверил и нашёл верным

- **Утечки файла нет:** артефакт отдаётся только из ветки, требующей пользователя и членства; переход по ссылке без заголовка
  даёт 401, и это утверждается для всех файлов. В исходниках консоли нет ни одного `href` на адрес API.
- **Р-143 держится:** `second_factor_present` требует одновременно совпадения вида, живой аренды, состояния RUNNING и признака
  «создано со вторым фактором»; четыре читающих вида не названы ни у одного стража, и правило 0112 это закрепляет.
- **Р-144 сквозной:** консоль пропускает по числу предложений посчитанного плана, хранилище — по заданию, база — по счёту
  различных предложений в транзакции. Живой прогон проверяет обе стороны настоящим входом одним паролем.
- **Стражи на уровне оператора не ослабли:** считают по всей транзакции, а не по таблице переходов, поэтому разбиение на
  несколько операторов их не обходит; RLS не даёт одному оператору вставить строки двух тенантов.
- **`effective_*_price_with` алгебраически совпадают с `effective_*_price`** — сверено построчно во всех четырёх сочетаниях
  «кандидат есть/нет × уровень единицы активен/неактивен».
- **Отмена и аренда:** гонка «отмена против взятия в работу» закрыта `FOR UPDATE SKIP LOCKED` и перепроверкой состояния под
  блокировкой строки; отменённое задание не берётся и не переписывается.
- **Фоновый исполнитель не задет новыми триггерами:** его роль не административная, поэтому тики хода не идут в аудит.
- **CSV-инъекция закрыта** во всех новых файлах, включая сырое значение из выгрузки продавца; имя файла санируется сервером.
