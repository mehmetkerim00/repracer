# Проверка истории перед переводом репозитория в публичные

Причина перевода: у приватного репозитория кончились оплаченные минуты GitHub Actions, и три шага (30, 31, 32) остались
непроверенными. На публичных репозиториях Actions бесплатны без ограничения минут.

Проверялась **вся история git, а не текущее дерево**: удалённый из файла секрет остаётся в истории и доступен любому, кто
клонирует репозиторий.

## Область

| | |
|---|---|
| Коммитов | 101 |
| Объектов (уникальных блобов) | 3393 |
| Размер `.git` | 6,0 МБ |

Просматривалось СОДЕРЖИМОЕ каждого блоба, включая файлы, которых в текущем дереве уже нет.

## Что искали и что нашли

| Что искали | Найдено |
|---|---|
| Ключи и токены (LWA, AWS, gh, ZITADEL, Kaufland), приватные ключи, JWT | Только синтетика — см. ниже |
| Строки подключения к базам с паролем | Одна, в модульном тесте: `postgres://svc_app:s3cr3t@db/repracer` |
| Содержимое `.env` | Нет. В истории только `*.env.example` с подстановками |
| Вебхуки с токеном в пути [Р-40] | Нет. Адреса отметки — `hc-ping.com` с нулевыми и единичными UUID |
| Реальные идентификаторы продавцов, ASIN, аккаунтов | Нет. Все — по шаблону (`B062…`, `A2SYNCOMP00001`) |
| Внутренние адреса | Только подстановки в примерах конфигурации (`clickhouse.internal`, `redpanda.internal`, `ops@example.invalid`) |
| Файлы, удалённые из дерева | Два: фикстура Amazon и временный workflow `infra-debug.yml` — в обоих только синтетика |

Все совпадения по шаблонам ключей оказались одним из четырёх:

1. **Собственные примеры AWS из документации** — `AKIAIOSFODNN7EXAMPLE` и парный к нему секрет. Это опубликованные AWS
   тестовые векторы для проверки подписи SigV4; по ним и сверяется наша реализация.
2. **Синтетика с приставкой `syn-`** — `Atzr|syn-refresh-token-0001`, `amzn1.application-oa2-client.syn0001`,
   `AKIASYNTHETIC0000001`.
3. **Временные пароли контейнеров CI** — `ci-synthetic-only`, `ci-synthetic-ingest`: живут внутри одного прогона, задаются
   в самом workflow, за его пределами ничего не открывают.
4. **Публичные константы** — `A1PA6795UKMFR9` и `ATVPDKIKX0DER` (идентификаторы витрин amazon.de и amazon.com).

Отдельно проверено: в workflow нет ни одной ссылки на секреты репозитория (`secrets.*`), и в самом репозитории секреты не
заведены — перевод в публичные ничего не ломает и ничего не открывает.

## Снимки спецификаций (`vendor/`)

Это единственное место, где нашлось то, о чём нужно было принять решение.

| Снимок | Лицензия | Решение |
|---|---|---|
| Модели Amazon SP-API | **Apache License 2.0**, объявлена самими файлами (`info.license`) | Публикуется; лицензия и происхождение названы в [NOTICE.md](../../NOTICE.md) |
| Спецификация Kaufland Seller API | **Лицензии нет** — только контакт поддержки | Решение владельца: публиковать как есть |

Спецификация Kaufland отдаётся публично и без авторизации по `https://sellerapi.kaufland.com/swagger.json`, хранится
неизменённой, с датой снятия и SHA-256. Она нужна, чтобы было видно, ПО КАКОЙ ИМЕННО версии сгенерирован клиент и
написаны консервативные правила адаптера. В NOTICE.md сказано прямо: права принадлежат Kaufland, копия будет удалена по
запросу правообладателя.
