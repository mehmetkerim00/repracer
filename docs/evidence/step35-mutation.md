# Шаг 35. Мутационная проверка схемы

Локальный прогон ПОЛНОГО каталога на окончательном коде шага: **405 мутаций из 405 пойманы своей проверкой**, 83 строки
каталога, ложных строк ноль, «упала только соседняя» — ноль. Итог CI — в строке статуса шага. Здесь — что добавилось и
что каждая новая мутация проверяет.

Новых строк каталога две; новых мутаций восемь — две добавило ревью шага (находки 16 и 17).

| Строка | Мутация | Своя проверка |
|---|---|---|
| Р-152 | снять `onboarding_path_known` | путь с несуществующим именем принимается |
| Р-152 | убрать из `onboarding_status` условие «источник отдал остаток» | пустой источник засчитывается сделанным шагом |
| Р-152 | считать в шаге синхронизации все единицы, а не включённые | выключение синхронизации не двигает шаг |
| Р-152 | отдать видам заданий остатков право `MANAGE_PRICING` | менеджер остатков не может ввезти остатки |
| Р-152 | объявить административным действием таблицы источников `MANAGE_PRICING` | менеджер остатков не может завести источник |
| Р-152 | объявить административным действием ключей Inbound API `MANAGE_PRICING` (находка 16) | менеджер остатков не может завести ключ |
| Р-152 | убрать сужение набора из шага синхронизации (находка 17) | сужение не меняет число предложений шага |
| Р-105 (шаг 35) | вернуть проверку «цена равна решению» в одно выражение с `field = 'PRICE'` | шестая запись остатка в сессии отказывает по праву |

Последняя — про дефект, который шаг нашёл и исправил. Проверка «цена равна решению» стояла одним выражением
`NEW.field = 'PRICE' AND NOT EXISTS (… price_decision …)`. Первые пять исполнений в сессии PL/pgSQL планирует под
конкретные значения и подзапрос сворачивает; с шестого берёт общий план, и подзапрос остаётся — роль остатков [Р-105],
у которой нет права читать `price_decision`, получала отказ ПРАВА на шестой записи количества. Смоук шага 19 вставлял
не больше пяти и этого не видел; нашёл конвейер остатков на 200 предложениях.

Мутация возвращает прежнюю форму, и смоук, вставляющий восемь количеств одной сессией, краснеет.
