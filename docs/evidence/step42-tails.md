стало. Одиннадцать находок, закрыты все; две из них закрыты ПРАВИЛОМ, а не правкой [Р-146].

## Две находки красного прогона CI шага 41

Полный прогон шага 41 ([36236154298](https://github.com/mehmetkerim00/repracer/actions/runs/36236154298)) был красным в двух заданиях; разбор
открыл шаг 42.

**1. Задание `shadow-day` не запустило НИ ОДНОГО теста** — `BUILD RED: неизвестная область прогона «shadow»`. Список
областей жил в двух местах: `scripts/test-scopes.mjs` знал, какие файлы брать, `scripts/test-all.mjs` — какое значение
считать известным, и новая область попала только в первый. Список сведён в один (`SCOPES`), а вторую половину держит
правило [Р-146]: область из CI названа в списке И выбирает хотя бы один файл. Пустая область была бы хуже неизвестной —
задание зеленело бы, ничего не проверив, поэтому правило проверяет и это, с положительным контролем на имени `shadow-day`.

**2. Замер сжатия упал строкой `null value in column "shadow"`.** Замер копирует таблицу (`LIKE … INCLUDING DEFAULTS`) и
перечислял ВСЕ её столбцы, поэтому новый NOT NULL столбец получал NULL вместо своего умолчания. Теперь называются только
столбцы, которые заполняет генератор; столбец БЕЗ умолчания по-прежнему называется — и вставка честно отказывает, потому
что тогда генератор обязан его заполнять. Ключи берутся у первой строки партии, а не отдельным вызовом генератора: у
него есть состояние, и лишний вызов сдвинул бы данные замера.
