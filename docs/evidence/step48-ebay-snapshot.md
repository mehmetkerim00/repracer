## Проверка по содержимому

- **«Authorization» — общее руководство по авторизации**, а не отдельная страница OAuth scopes. В нём есть раздел
  «Working with OAuth scopes», но перечня scope eBay нет: список scope своего приложения портал показывает на странице
  Application Keys. Scope операций взяты из `security` спецификаций.
- **Growth Check — отдельная страница**: проверка нужна, чтобы поднять лимиты и использовать restricted API в бою. Её
  требования лежат в руководстве Get Started, которого в снимке нет.

## Что открылось нового

- **E-18 закрыт документацией.** До первого боевого вызова приложение подписывается на уведомления Marketplace Account
  Deletion или оформляет исключение «Not persisting eBay data». Мы данные eBay храним, поэтому нужна своя конечная точка
  (проверка challenge-кодом, подтверждение каждого уведомления). Без неё боевой ключ не активируется — работа
  следующего шага.
- **Р-4 и Identity.** У бизнес-аккаунта scope `commerce.identity.readonly` возвращает весь `businessAccount`: имя, адрес,
  почту, телефон. Более узкого scope только для `userId` в спецификации нет. Код разбирает только `userId`; тело не
  хранится и не пишется в журнал.
- **E-21, E-22** — новые вопросы (раздел 9).
