## 3. OWASP — что вошло

1. **Ограничение частоты** — в HTTP-слое консоли, до разбора тела и проверки входа:
   - окно 60 с на ключ клиента: SHA-256 от `Authorization` или адрес клиента;
   - `X-Forwarded-For` учитывается только за доверенным прокси;
   - отказ — `429 RATE_LIMITED` с `Retry-After`.
2. **Полная CSP консоли** — только свой код и origin поставщика identity в `connect-src`.
3. **Закрепление:**
   - действия GitHub — по SHA;
   - образы CI и всех `deploy/*/compose.yaml` — `тег@sha256`.

Не вошли (журналы ≥ 12 месяцев, шифрование копии, изоляция панели) — первая строка плана шага 54, с оценками в
[step52-owasp.md](step52-owasp.md).

## Новые вопросы

- Пределы частоты (600 и 120 запросов в минуту) — оценка, а не замер. Нужен замер на пилоте: сколько запросов делает экран за
  минуту работы продавца.
- Ограничитель живёт в памяти процесса. При нескольких репликах консоли предел умножается на их число — общий счётчик нужен
  только с появлением второй реплики.
