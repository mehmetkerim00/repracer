# Шаг 64: проход консоли глазами клиента из США

Первый пилотный клиент — продавец из США: Amazon и eBay, витрины US, доллары, английский язык. Консоль выросла и прогонялась на EBAY_DE
и Kaufland в евро по-немецки. Проход сделан четырьмя способами:

1. Живой прогон нового владельца-американца через HTTP как браузер —
   [apps/console/test/pilot-us-live.pg.test.ts](../../apps/console/test/pilot-us-live.pg.test.ts). Он проходит весь путь на английском:
   - база региона US, тенант на английском, приглашение и вход;
   - онбординг, подключение eBay EBAY_US, вопрос Р-202 про другие инструменты и подтверждение записи количества;
   - себестоимость в USD файлом, границы, стратегия, включение, тень, «почему эта цена»;
   - остатки, возвраты, отчёт тени;
   - перевод в бой в стенде, запись цены $12.99 и обратное чтение.

   На каждом экране прогон проверяет, что нет немецких следов (`äöüß„“€`, EUR) и что суммы записаны как `$12.99`.
2. Демо с профилем США — [apps/console/test/demo-us-live.pg.test.ts](../../apps/console/test/demo-us-live.pg.test.ts): гость видит аккаунты
   eBay US и Amazon US в тени, вопрос о других инструментах задан по-английски.
3. Чтение всех английских текстов словаря ([packages/console-model/src/i18n/en.ts](../../packages/console-model/src/i18n/en.ts)) и экранов
   `apps/console/src/screens` — ревьюер, только чтение.
4. Проход демо-мира как владелец по сценарию показа ([docs/demo-script.md](../demo-script.md)), поднятого одной командой
   `scripts/demo-prepare.sh`, — через API стенда с английской локалью.

## Что проход подтвердил без изменений

- Деньги в USD форматируются `$12.99` и `$1,234.56` (en-US); евро у витрин США нигде не появился.
- Причины отказов понятны и называют действие: «Another tool updates stock in this channel: if we wrote stock too, the two would
  overwrite each other…», «The typed text does not match the channel account ID. Type it exactly as shown.».
- Гость демо не может ответить на вопрос о других инструментах (403); наблюдатель не видит кнопок, которые ему не разрешены.
