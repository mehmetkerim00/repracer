# Шаг 68: ревью

Ревьюер — отдельный агент, только чтение: рабочее дерево против `main`. Проверка типов затронутых пакетов — 0 ошибок, юнит-тесты модели
экранов — 30 из 30; тесты на PostgreSQL ревьюер не запускал. Подтверждено без находок:

- административная роль читает таблицу подреза и справочник витрин;
- второй фактор при посеве демо — как у посева стенда;
- цикл тени США останавливается и при закрытии консоли, и при пересеве;
- убранная заглушка не ломает выгрузки и архив: `describe()` зовут только экраны и проблемы предпросмотра;
- тексты CAPPED_* «цель из цен конкурентов» верны: их выпускают только стратегии, идущие за рынком.

**9 находок: 0 критичных, 3 существенные, 6 мелких.** Исправлены все.

Найдено сверх ревью, до него:

- модуль США писал алерты демо в базу (`PgAlertSink`), а Kaufland-демо держит их в памяти — доставка в работе отправила бы письма на
  синтетический адрес владельца демо; теперь алерты США — в памяти, число — в журнале прожатия;
- правило «настоящие часы — только через `systemClock`» поймало `Date.now()` в новом модуле;
- немецкие тексты с «(Frage E-21)», «(A-16)», «(E-01)»: правило словаря держит теперь и коды вопросов каналов.
