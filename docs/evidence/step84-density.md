# Шаг 84: насыщение вида — плотность, слои, доводка

Владелец по живым экранам шага 83: база Primer принята, вид «правильный, но бедный». Шаг — про плотность, слои и доводку, не про декор:
градиенты, анимации, тёмный hero и аватары шага 82 не возвращались. Все значения — токены Primer (`@primer/primitives`); правило-тест
`apps/console/test/design-tokens.test.ts` держит это и для новых значений.

Снимки 12 экранов сценария — `docs/evidence/step84-design/` (демо после перезапуска, EN).

## Что сделано

1. **Слои.** Канва контента — `--bgColor-muted` (canvas.subtle); карточки, таблицы и панели — белые (`--bgColor-default`) с границей,
   радиусом и тенью покоя Primer (`--shadow-resting-small`, токен `--shadow`). Шапка — тёмная.
2. **Ширина.** Контент рабочего пространства — единые отступы и предел ширины по центру своей колонки. «Your workspaces» — сетка карточек
   320–400px; в карточке — имя крупно, пилюли, ряд мини-показателей (подпись мелко muted, под ней число табличными цифрами: Offers,
   Decisions 24h, Interventions 7d) вместо строки через точки, роль — подписью.
3. **Вход.** Группа «знак + карточка» — по центру окна по вертикали, фон — канва. Роли — одной колонкой строками: кружок цвета шкалы
   Primer Label (у каждой роли свой: синий, фиолетовый, оранжевый, зелёный, бирюзовый, серый), имя роли полужирным и одной строкой, что
   роль может, — по матрице прав `PRICING_PERMISSIONS` (policy.ts), термины по глоссарию. «Sign in as …» — доступное имя кнопки.
4. **Таблицы.** «Price changes»: причина, одинаковая у многих строк (у тени — «Not sent: this channel account is in shadow mode…»), —
   один раз строкой при полосе итогов; в строке остаётся основание решения («Buy Box», «Beat the lowest»), строки одноэтажные; своя
   причина строки остаётся в строке, полный текст — в «Decision path». «What your bounds prevented»: стандартная причина удержания
   (цель прижата к минимальной цене или к полу маржи) — короткой формой, заголовком причины, полный текст — подсказкой; иная причина —
   целиком. Пояс времени («UTC−7») — один раз в шапке колонки времени, если у всех строк он один; при разных поясах (переход часов в окне) —
   у каждой строки. Шапка таблиц — канва, наведение строки, числа вправо — как прежде.
5. **Shadow mode.** Плитки одной высоты, числа на одной линии (строка подписи зарезервирована у каждой плитки), «not a forecast» — muted.
   График «Decisions per day» — столбики цвета успеха Primer (`--bgColor-success-emphasis`): дневные счётчики дискретны, столбик
   читается лучше линии; ось значений с 3–4 «круглыми» делениями, линии сетки цветом `--borderColor-muted`, число над столбиком у недели,
   у месяца — подсказкой. Текстовый блок — список «показатель — значение» с разделителями (Period; floor — K times; ceiling — 0 times;
   writes held — X — prices P, stock S; budget — about N; without the floor — $…), оговорки — muted-сноской под списком. Смысл тот же, что у
   строк сводки; сами строки остались для недельного письма. Модель — `shadowSummaryList` с юнит-тестом (обе сноски и контроль без них).
6. **«Demo» — два уровня.** Пометка стенда в шапке («test environment, synthetic data») — только вне рабочего пространства (вход, список);
   внутри — жёлтая полоса и пилюля у заголовка.
7. **Фильтры «Price changes»** — одним рядом одной высоты (поиск и выбор предложения — в строку), счётчик найденного — справа muted;
   выгрузка «All N entries as a file» — в полосе итогов таблицы (действие над таблицей).

Тексты экранов не менялись. Новые подписи — к новым элементам, на обоих языках: показатели карточки рабочего пространства, «что может
роль», подписи списка сводки тени.

## Сценарий и чеклист

`docs/demo-script.md`, `docs/demo-preflight.md`: вход — строка «Owner» («full access, can stop pricing and switch on live writes») вместо
кнопки «Sign in as Owner»; карточка магазина — показатели Offers / Decisions 24h / Interventions 7d; пометка стенда в шапке — только вне
магазина; график — столбики с числами, «сегодняшний столбик» вместо «точки»; сводка — список «показатель — значение» и сноска.

- Браузерный смоук — 1 из 1, ошибок страницы 0 (смоук нажимает роль по доступному имени и ждёт описание роли).
- Правило токенов, модель экранов (в том числе новый тест списка сводки), словари, консоль без базы, отдача статики, контрактные тесты
  консоли, правила репозитория — 107 из 107; проверка типов — 0 ошибок; импорты страницы — нарушений 0; полнота сборки — 147 файлов.
- Живые прогоны тени на PostgreSQL (витрина США, демо США) — 8 из 8.
- Проход сценария EN с действиями (вход → тень → отказ перевода в бой → «Why this price» → «Bounds and floor» → стоп-кран → подключения →
  остатки) — все шаги, ошибок страницы 0; все 23 экрана EN — ошибок 0; DE — стоп-кран по-немецки и экран тени, ошибок 0.
- После перезапуска демо (88 с, `caffeinate -dims` держит машину): пять строк ролей с доступными именами «Sign in as …», карточка входа
  по центру; показатели Offers / Decisions 24h / Interventions 7d; пометка стенда в шапке есть на списке и нет внутри магазина; 7 столбиков,
  ось 0 / 100 / 200; 6 строк сводки и 2 сноски; пояс « · UTC−7» в шапке колонки; канва `rgb(246, 248, 250)`, у карточек тень Primer.
