# @repracer/channel-port

Порт `ChannelAdapter` — контракт, который реализуют адаптеры всех каналов. Только типы и три защитные функции
определения необязательных возможностей. Обоснование — [ADR-0006](../../docs/adr/0006-channel-port.md).

| Файл | Содержимое |
|---|---|
| `src/primitives.ts` | Идентификаторы, деньги, идентичность оффера, контекст вызова |
| `src/descriptor.ts` | `ChannelDescriptor`: единицы записи, пакеты, бюджеты правок, лимиты, подтверждение, побочные эффекты, предусловия |
| `src/messages.ts` | Записи, план отправки, исходы, наблюдения, конкуренты, офферы, заказы, входящие события |
| `src/errors.ts` | `ChannelError` и классы `TRANSIENT` / `PERMANENT` / `REQUIRES_HUMAN` |
| `src/adapter.ts` | `ChannelAdapter`, зависимости адаптера, необязательные возможности |

Правила для реализаций:
1. Каждый вызов начинается с `accounts.verify(ctx.tenantId, ctx.channelAccountId)`; несовпадение — `TENANT_MISMATCH` и алерт, без обращения к каналу [Р-31].
2. Адаптер не хранит состояние синхронизации и не решает, повторять ли запись.
3. Никаких PII покупателей в возвращаемых данных [Р-4].
