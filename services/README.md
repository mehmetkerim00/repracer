# services/

Развёртываемые единицы.

| Сервис | Назначение |
|---|---|
| [scheduler](scheduler/) | Процесс-планировщик периодических работ [Р-126, Р-127, Р-129] (точка входа `src/main.ts`, развёртывание — [deploy/scheduler](../deploy/scheduler/), отметка во внешнем сервисе, метрики и `/healthz`, сроки — по часам базы): ярусный опрос, проверка потерь уведомлений, сверка Amazon по кругу, выгрузка суток в ClickHouse, закрытие суток цен, обход офферов, секции и удаление по сроку. Один экземпляр на работу — аренда в базе; пропущенные суточные слоты выполняются по очереди; алерты отставания; журнал запусков ([docs/evidence/step25-scheduler.md](../docs/evidence/step25-scheduler.md)) |
| [pricing-worker](pricing-worker/) | Экземпляр пути решения за брокером: снимки конкурентов → оценка [Р-59]; события единицы записи → диспетчер [Р-64]; обход-страховка; ретранслятор outbox под advisory lock [Р-34]. Экземпляров — сколько угодно ([ADR-0009](../docs/adr/0009-write-dispatcher-and-broker.md)) |

Топология развёртывания (модульный монолит или сервисы) по-прежнему не решена — [ADR-0001](../docs/adr/0001-event-driven-architecture.md),
раздел «Что не решается». `pricing-worker` запускается одним процессом на экземпляр; конфигурация — переменные окружения.
